# Police vehicle asset provenance

This specialist branch contains prototype police vehicle geometry and project-original decal textures created for Grand Bruxelles Game.

- `police_bilingual_decal.png`: project-original placeholder marking; not an official police logo or livery asset.
- `police_blue_stripes.png`: project-original placeholder stripe texture; not copied from a third-party game.
- `police_rear_chevrons.png`: project-original placeholder rear-safety pattern.
- `police_patrol.tscn`, `police_civil.tscn`, `police_bab_van.tscn`: in-engine prototype geometry assembled from Godot primitive meshes.

These assets are integration placeholders, not photo-match-complete production models. They must be replaced or refined against lawful real Brussels/Belgian police references before being classified as realism-complete. The gameplay/light API should remain stable so higher-detail licensed meshes can replace the prototype bodies without rewriting police gameplay.
