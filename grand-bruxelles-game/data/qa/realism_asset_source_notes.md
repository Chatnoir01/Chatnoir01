# Source license notes

- Sketchfab candidates in this intake are included only when their public model page declares a Creative Commons license compatible with review; the exact downloaded package still needs its own archived provenance/hash before import.
- Adobe Mixamo FAQ currently states that Mixamo characters and animations may be used royalty-free in video games; raw redistribution rights are not inferred from that statement.
- Mixamo Additional Terms prohibit using Mixamo content/data/output to directly or indirectly create, train, test or improve machine-learning/AI systems.
- MakeHuman core assets are CC0; contributed packs can differ and must be checked per pack.
- Poly Haven states that its HDRIs, textures and 3D models are CC0 and can be used commercially and redistributed.
- Kenney Car Kit is CC0 and remains a lawful low-cost fallback/reference source, but visual quality must still pass the player gate before production use.
