# Grand Bruxelles — Visual Masterlist

Production truth: GitHub `main` only. This document is a visual-production backlog, not a claim that a zone is complete.

Baseline used for this first pass: `a8aaf43f6393a6e9125d5548f00727e0972cc5c7` (publication head; substantive parent includes Bourse sidewalk runtime #209).

## North star

For every zone, ask: **if a real Brussels photo is placed beside the game capture, what immediately reveals the game?**

A technical green check does not equal visual approval. A lot should move toward a visible runtime improvement, deterministic capture, and human comparison whenever possible.

## Status vocabulary

- `missing`: element absent from production.
- `references_needed`: useful source/photo reference not yet locked.
- `references_found`: defensible source/reference exists.
- `geometry_exists`: geometry exists but may not be mounted or visually final.
- `runtime_exists`: visible in production runtime.
- `visual_gap_high`: immediately harms recognition/credibility.
- `ready_for_asset_work`: enough reference exists to build an asset/material.
- `ready_for_photo_match`: deterministic camera/reference pair exists.
- `validated_visually`: human-reviewed capture is acceptable for the current milestone.

## Reference acquisition rules

1. Prefer official geometry/elevation/transport sources: Paradigm/UrbIS/UrbIS3D, Brussels Mobility, STIB, official orthophoto/DTM/DSM.
2. Use OSM as a complement, not as proof for unresolved geometry/traffic semantics.
3. For photo reference, store lawful URL/metadata, camera position/direction where known, date if relevant, and a short statement of what the image proves.
4. Do not import copyrighted reference imagery as distributable game assets unless licensing clearly permits it.
5. Avoid giant random image dumps. Acquire references for the exact 300–500 m slice or hero discrepancy currently being built.

## Definition of a visually complete micro-slice

A 300–500 m slice is ready to call visually convincing only when:

- hero/major building silhouette is recognisable;
- ground/street/sidewalk proportions are defensible;
- immediate façades are not generic placeholders;
- key furniture/signage/transport vocabulary is present;
- materials have believable roughness/normal/scale;
- vegetation and parked/street activity fit the reference;
- at least three deterministic cameras have been compared against real references;
- the top three visible discrepancies from the previous review have been addressed or explicitly blocked by missing evidence;
- performance remains acceptable;
- a human reviewer would not identify a single huge prototype giveaway in the first three seconds.

## Direction rule for future lots

Prefer **one obvious visible improvement** over several low-visibility evidence additions when both are equally safe and source-backed. Evidence work remains necessary, but it should unlock runtime change. After every acceleration, require a human visual inspection of the resulting capture.
