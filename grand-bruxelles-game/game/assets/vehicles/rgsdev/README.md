# Rgsdev CC0 vehicle pack

Source: **Free Low Poly Vehicles Pack by Rgsdev (Raphael Gonçalves)**.
License: **CC0 / public domain**. See `LICENSE-RGSDEV-CC0.txt`.

This directory is the runtime source for the drivable/traffic vehicle integration on branch `codex/rgsdev-drivable-vehicles`.

## Included models

- ambulance.fbx
- bus.fbx
- firetruck.fbx

- police_sedan.fbx
- police_sports.fbx
- police_suv.fbx
- roadster.fbx
- sedan.fbx
- sports.fbx
- suv.fbx
- taxi.fbx
- truck.fbx
- truck_with_trailer.fbx
- van.fbx

The FBX files are kept intact from the uploaded CC0 pack. Vehicle visuals retain separate wheel objects so wheel spin/steering can be animated. Driver logic is intentionally separated from the visual asset so player control and future NPC drivers can share the same vehicle instances.
